# Banda APK

Site da Banda APK (bandaapk.com.br): banda de apoio de festivais de canto e shows para eventos no RS, SC e PR.

Site estático em `public/` (index.html e img/), sem build. Publicado na Cloudflare (Worker com arquivos estáticos, `wrangler.jsonc`) a cada push na branch `main`, já ligado a bandaapk.com.br e www.
